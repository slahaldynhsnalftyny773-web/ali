# مختبر JavaScript — مستكشف الأمثلة

موقع تعليمي تفاعلي عربي RTL مبني باستخدام HTML وCSS وJavaScript فقط.

## المزايا
- مكتبة أمثلة للصفحات العشر: البداية، المتغيرات، أنواع البيانات، ومجموعات العوامل الستة.
- بحث وتصفية حسب الدرس.
- مدخلات قابلة للتغيير، تشغيل وإعادة ضبط، ومعاينة المخرجات داخل iframe معزول.
- سجل تشغيل وشرح ونصيحة لكل مثال.
- نسخ الكود، مظهر داكن/فاتح، وتصميم متجاوب.
- روابط إلى صفحات هرمش الأصلية.

## التشغيل
افتح `index.html` في متصفح حديث.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد إلى الجذر.
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch، ثم الفرع `main` والمجلد `/(root)`، واضغط Save.
4. افتح رابط الموقع الذي يظهر في صفحة Pages.
